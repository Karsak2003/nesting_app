# IAGI (Intelligent Agent Gravitational Imitation)

IAGI — это система оптимизации раскроя плоских деталей на материалах, использующая физическое моделирование гравитационных взаимодействий. Она предназначена для решения задач оптимизации размещения фигур на двухмерных материалах с учетом различных технологических ограничений.

## Особенности

- **Физическое моделирование**: Использование гравитационных взаимодействий для оптимизации размещения
- **Поддержка форматов**: Входные файлы в форматах DXF и STEP
- **Множество алгоритмов**: Последовательный, параллельный и гибридный подходы к размещению
- **Технологические ограничения**: Учет приоритетов, ориентации, зон дефектов и других факторов
- **Графический интерфейс**: Возможность визуализации процесса и результатов
- **Модульная архитектура**: Легкое расширение и модификация системы

## Архитектура

Система состоит из следующих основных компонентов:

- **Geometric Kernel**: Обработка геометрии на основе OpenCASCADE
- **Agent System**: Агенты с физическими свойствами
- **Physics Engine**: Моделирование взаимодействий и движения
- **Collision Detection**: Обнаружение пересечений
- **Optimization Module**: Алгоритмы упаковки
- **Constraint Management**: Учёт ограничений
- **Layout Engine**: Генерация компоновок

## Установка

Для установки зависимостей выполните:

```bash
conda env create -f environment.yml
conda activate iagi_env
```

## Используемые пакеты
Проект использует следующие сторонние пакеты:

- **OpenCASCADE** — библиотека для работы с геометрическими объектами
- **PythonOCC** — Python-обертка для OpenCASCADE
- **NumPy** — вычисления с массивами данных
- **SciPy** — научные вычисления
- **Matplotlib** — визуализация данных
- **Shapely** — операции с геометрическими фигурами
- **GDAL/OGR** — обработка геометрических данных из файлов

## Использование

Запуск системы:

```bash
conda activate iagi_env
python main.py
```
