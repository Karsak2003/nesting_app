# IAGI Client GUI

Клиентское приложение для системы оптимизации раскроя плоских деталей (ИАГИ).

## Структура проекта
Проект разделен на модули для удобства поддержки:
- `config.py`: Управление настройками (JSON).
- `visualization.py`: Виджет отрисовки на базе Matplotlib.
- `dialogs.py`: Диалоговые окна (подключение, загрузка, сплэш-скрин).
- `panels.py`: Панели управления и мониторинга.
- `main_window.py`: Главное окно, собирающее все компоненты.
```
iagi_client/
├── setup.py                     # Конфигурация установки пакета
├── README.md                    # Краткая инструкция
├── main.py                      # Точка входа (запуск приложения)
└── gui/                         # Основной пакет
    ├── __init__.py              # Инициализация пакета и экспорт основных классов
    ├── config.py                # Управление настройками (JSON)
    ├── visualization.py         # Виджет отрисовки Matplotlib
    ├── dialogs.py               # Диалоговые окна (Подключение, Загрузка, Сплэш)
    ├── panels.py                # Панели управления и мониторинга
    └── main_window.py           # Главное окно приложения (сборка всего вместе)
```

## Установка

1. Убедитесь, что у вас установлен Python 3.8+.
2. Откройте терминал в корневой папке проекта (`iagi_client_package/`).
3. Установите пакет в режиме разработки (все изменения в коде будут применяться мгновенно):
```bash
   pip install -e .
```
