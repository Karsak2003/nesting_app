# Клиентская часть ИАГИ

Клиентское приложение на PyQt5 с HTTP-клиентом для подключения к серверу ИАГИ.

## Установка зависимостей

```bash
pip install PyQt5 requests numpy scipy shapely rtree matplotlib ezdxf pyyaml scikit-learn tqdm joblib
```

## Запуск клиента

```bash
cd client
python main.py
```

## Настройка подключения

При запуске клиент автоматически пытается подключиться к серверу по адресу `http://localhost:8000`.

Для изменения адреса подключения:
1. Нажмите кнопку "🔌 Подключение..." в верхней панели
2. Введите адрес сервера (например, `http://192.168.1.100:8000`)
3. Или выберите пресет "Локальный" / "Удаленный"
4. Нажмите "OK"

## Цветовые темы

Приложение поддерживает три цветовые темы:

### Способы смены темы

**Через меню:**
1. Меню "Настройки" → "Цветовая тема"
2. Выберите: "Системная", "Светлая" или "Тёмная"

**Через диалог подключения:**
1. Нажмите "🔌 Подключение..." 
2. В разделе "Цветовая тема" выберите нужную тему
3. Нажмите "OK"

### Описание тем

- **Системная** - автоматически определяет тему вашей операционной системы
  - Windows: использует настройку "Параметры" → "Персонализация" → "Цвета"
  - macOS: следует системной теме (светлая/тёмная)
  - Linux (GNOME): использует gsettings color-scheme
  
- **Светлая** - классический светлый интерфейс
  - Светлый фон (#FFFFFF)
  - Тёмный текст (#000000)
  - Синие акценты (#3A7BD5)
  
- **Тёмная** - современный тёмный интерфейс
  - Тёмный фон (#2D2D2D)
  - Светлый текст (#FFFFFF)
  - Голубые акценты (#5A9FD5)
  - Уменьшенная нагрузка на глаза

Настройки темы сохраняются между запусками приложения.

## Возможности

- Выбор файла с фигурами (DXF, STEP)
- Настройка параметров оптимизации:
  - Профиль конфигурации (точность)
  - Алгоритм размещения
  - Технология резки
  - Минимальный зазор
  - Размеры листа
- Мониторинг прогресса оптимизации в реальном времени
- Экспорт результатов в форматах DXF, SVG, JSON
- Журнал событий

## Работа с сервером

Клиент работает только при подключенном сервере. Если сервер недоступен:
- Индикатор подключения покажет красный статус
- Кнопка запуска оптимизации будет неактивна
- Можно изменить адрес сервера через меню "Файл" → "Подключение к серверу..."
